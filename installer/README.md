# Інсталятор

`ukrainizer-setup.exe` — один файл, який можна просто віддати людині.

## Зібрати

```
py installer/make.py
```

Результат: `installer/dist/ukrainizer-setup.exe` (~41 МБ). Ані `build/`, ані
`dist/` у git не йдуть: усе складається з того, що в репозиторії вже є.

## Що всередині

**Тільки джерела перекладу й патчер** — те, що відстежує git (548 файлів,
14,8 МБ). Готових `.esm` там немає, і це не оптимізація розміру:

* зібраний `Morrowind.esm` — це 80 МБ даних Bethesda з підміненим текстом;
* `tools/corpus.json` і `tools/books/_source.json` — англійські репліки й проза
  книг, вигружені з гри;
* `Fonts/*.ttf` — Pelagiad під ліцензією SIL OFL **із зарезервованою назвою**,
  тож роздавати змінений файл під тим самим іменем не можна.

Тому список файлів пакунка бере `git ls-files`: межу між «наше» і «чуже» вже
проведено в `.gitignore`, і другого разу її проводити не треба. Патчимо файли
на машині гравця — його власну копію гри і його власний шрифт.

## Що робить інсталятор

1. шукає `openmw.cfg` — він і описує, яка гра та які моди стоять;
2. розпаковує переклад у `<поруч із конфігурацією>/mods/...`;
3. проганяє ті самі кроки, що й `build.py`;
4. дописує `data=` **останнім** рядком (виграє останній) і `encoding=win1251`.

Копія конфігурації лишається поруч як `openmw.cfg.ukr-backup`.

```
ukrainizer-setup.exe                  # знайти все саме
ukrainizer-setup.exe --cfg <шлях>     # вказати openmw.cfg вручну
ukrainizer-setup.exe --dry-run        # лише показати, що зробить
ukrainizer-setup.exe --uninstall      # прибрати за собою
```

## Чого він НЕ робить

Не ставиться на оригінальний `Morrowind.exe`. Рушій 2002 року малює інтерфейс
растровими `.fnt`, а наш шрифт — TrueType із дорисованими Є І Ї Ґ. Гравець
побачив би порожні квадратики замість кожної української літери, тож інсталятор
про це прямо каже і виходить. Щоб підтримати старий рушій, треба окремо зібрати
кириличний `.fnt` — це інша робота, не пакування.

## Перевірено

Наскрізний прогін на **чистій** конфігурації (Steam-гра, три майстер-файли,
жодного мода):

```
Morrowind.esm   українською 21362 з 21365 (100%)
Tribunal.esm    українською  2527 з  6407  (39%)
Bloodmoon.esm   українською  2076 з  5977  (35%)
```

Tribunal і Bloodmoon — це наш поточний стан, а не хиба інсталятора.

## Пастки, на які вже наступали

* **Заморожений exe не є інтерпретатором Python.** `build.py` запускає кроки
  через `subprocess([sys.executable, script])` — усередині exe це не працює.
  Інсталятор виконує ті самі скрипти через `runpy` у своєму процесі.
* **Перехоплення виводу.** Кожен крок починає з
  `io.TextIOWrapper(sys.stdout.buffer)`, тож підмінити `sys.stdout` на
  `StringIO` не можна — у неї немає `.buffer`.
* **Консоль Windows не в UTF-8.** Без `SetConsoleOutputCP(65001)` гравець
  бачить мотлох замість українського тексту.
* **Шрифти рушія лежать не поруч із конфігурацією.** Типово `openmw.cfg` — у
  `Documents\My Games`, а рушій — у Program Files, тож іти вгору від
  конфігурації марно. Беремо `resources=` з неї або теку знайденого
  `openmw.exe`.
* **Шлях із пробілами.** `data=` без лапок обрізається по `My Games`.
